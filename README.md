# ML Challenge 2026 — Business Entity Resolution

## Problem

Match businesses from Source 1 with corresponding businesses
from Source 2 and Source 3 using noisy business names and addresses.

## Project Structure

- `dataset/` — Competition dataset (not committed to Git)
- `src/` — Main project code
- `notebooks/` — Data exploration and experiments
- `experiments/` — Experiment results
- `output/` — Final submission files

## Pipeline

1. Data preprocessing
2. Entity normalization
3. Candidate generation / blocking
4. Feature engineering
5. ML matching
6. Evaluation using Macro F0.5
7. Submission generation
